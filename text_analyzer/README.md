# text analyzer

A mini project from the little book of C.

Build a simple tool that reads a text file and reports basic statistics, including number of lines, words, and characters it contains. 

Requirements:
1. take a file name as a required command line argument.
2. open the file safely, reporting errors if it does not exist or cannot be read.
3. read the file line by line
4. count total characters, total words, and total lines.
5. compute the most commonly used words and characters.
6. print a summary at the end to stdout
